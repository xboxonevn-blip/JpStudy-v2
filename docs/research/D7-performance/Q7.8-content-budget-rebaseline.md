# D7.Q7.8 Content Budget Rebaseline

Date: 2026-06-23

## Finding

The D7 artifact budget failed after the local content corpus expanded. This is a
package-envelope change, not evidence that the first route now eagerly fetches
the full corpus.

Fresh release build evidence:

- Total `build/web` raw: `118,890,534` bytes.
- Total `build/web/assets` raw: `78,203,872` bytes.
- Total JSON raw: `75,303,796` bytes.
- Largest JSON families include examples, reading passages, Tatoeba seed data,
  conjugation lemmas, interlink graph, and conjugation corpus.

The app-shell budgets remain unchanged:

- `main.dart.js` raw/gzip.
- CanvasKit wasm raw/gzip.
- sqlite wasm raw/gzip.

## Decision

Rebaseline only the total package budgets:

- `totalBuildRawBytes`: `125,000,000`.
- `totalAssetsRawBytes`: `83,000,000`.
- `totalJsonRawBytes`: `80,000,000`.

This keeps a narrow allowance above the measured corpus size while preserving
strict checks for shell/runtime growth.

## Follow-Up

Keep D7 focused on route-specific fetch budgets. The root smoke test remains
the stronger beta signal for startup behavior because raw deploy size includes
lazy content that users should not fetch on first load.
