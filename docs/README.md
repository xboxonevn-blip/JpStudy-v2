# Docs

Project documentation is grouped by purpose:

- `docs/agent-directives.md`: mandatory agent working directives, including
  Directive D for connected, whole-flow audit and verification
- `docs/plans/`: active and historical implementation plans
- `docs/plans/legacy/`: older plan files kept for reference
- `docs/reports/`: generated audits, scorecards, and migration reports
- `docs/notes/`: design notes and one-off exploration docs
- `docs/specs/`: feature or product specs
- `docs/archive/`: historical docs kept out of the active reading path
- root docs files in `docs/`: stable reference docs such as schemas and third-party notes

Operational references:
- `docs/free-web-stack-reference.md`: free-tier hosting, Firebase boundaries,
  and redistribution-safe content-source guidance
- `docs/jlpt-exam-source-reference.md`: JLPT official workbook/audio,
  timing/scoring, and real-exam import policy

Recommended reading order:
- `README.md`
- `ROADMAP.md`
- `docs/free-web-stack-reference.md`
- `docs/jlpt-exam-source-reference.md`
- `docs/notes/2026-05-08-backup-sync-architecture.md`
- `docs/DATA_SCHEMA_V2.md`
- `docs/reports/`
